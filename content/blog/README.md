# Optional repository-managed Business Stories

These Markdown files are used only for the optional static article build. They are not the data store for the separate username/password CMS used by the CEO. For that workflow, see `CMS_SETUP.md` and use the Publisher Access page at `/admin/` after the CMS API is deployed.

Only Markdown files with `published: true` are included in the static build. Never store passwords, password hashes or access tokens here.
